arXiv

SpecMind: spectrum intelligence via multi-agent hybrid retrieval-augmented generation

Exponential wireless-device growth is pushing spectrum management toward fine-grained decisions across space, time, and device constraints, forcing policymakers and engineers to process large volumes of disaggregated, heterogeneous data — text and tables from diverse sources. SpecMind applies a multi-agent hybrid retrieval-augmented generation (RAG) pipeline to spectrum intelligence, letting specialized agents retrieve and reason over those mixed sources.

The design is a concrete pattern for LLM-driven spectrum analysis, where the retrieval layer must reconcile structured engineering data with unstructured policy text.

Why read it A direct LLM-plus-telecom application combining multi-agent orchestration with hybrid RAG — squarely in the spectrum-intelligence lane.
arXiv

TriSLA: a preventive closed-loop SLA architecture for multidomain 5G network slicing

Network slicing in multidomain 5G environments makes guaranteeing service level agreements (SLAs) hard under dynamic resource variability and heterogeneous service requirements. TriSLA is a closed-loop, preventive, SLA-aware architecture that evaluates feasibility at request time and continuously ensures SLA compliance during operation.

It targets the multi-operator, multi-domain slice orchestration problem where a single domain's decisions can break an end-to-end commitment — a concrete step for autonomous network management.

Why read it A concrete architecture for multidomain SLA assurance in slicing — relevant to autonomous network management and slice orchestration.

OpenAI

OpenAI designates Astra its first Critical-capability model and tightens cyber safeguards

OpenAI now assesses that Astra meets the Critical cybersecurity threshold under its Preparedness Framework — the first model designated at this level. It can find previously unknown flaws and build working exploit chains across well-protected systems without step-by-step human guidance: a perfect 100% score on ExploitBench, a full browser-compromise chain from an HTML file, and a local privilege-escalation chain to root on a hardened operating system. During evaluation it even discovered two zero-day vulnerabilities, now being disclosed to maintainers.

Release safeguards were strengthened after the Hugging Face incident: Astra refuses 91.5% of cyber-jailbreak requests (versus 59% for GPT-5.6 Sol), misalignment monitoring can stop unauthorized actions, and access to advanced cyber capabilities starts with a small tester group before expanding through Daybreak Blue.

Why read it A concrete, first-of-its-kind capability designation with real numbers — relevant to agent safety, frontier-model governance, and how cyber capabilities are gated.

Anthropic

Claude Fable 5.1 and Mythos 5.1: the same model, two safeguard dials, 45% cheaper agentic work

Anthropic released Claude Fable 5.1 (generally available) and Claude Mythos 5.1 (trusted access only) — the same model with different safeguard settings. Fable 5.1 leads Terminal-Bench-Science 0.1 at 52.6% (versus 24.7% for Fable 5) and CursorBench 3.2.0 at 73.4%. Mythos 5.1 tops Terminal-Bench 4.0 at 60.9% and, in early-access testing, designed protein binders with roughly 10x higher affinity than prior competition bests and sped up seven open-source genomics models up to 2.5x by writing custom GPU kernels.

The economics matter for agentic workloads: cache reads drop 75% to $0.25 per million tokens, cutting typical workload cost by about 25% and highly agentic workloads by up to 45%. A new Enterprise Frontier Safeguards system offers zero-data-retention privacy with customer-controlled cloud storage.

Why read it A concrete frontier-model release with hard benchmark numbers and a structural change in agentic cost economics — relevant to coding agents and inference budgets.
arXiv

ISO-RAG: isoperimetric noise control for multi-hop retrieval-augmented generation

Retrieval-augmented generation (RAG) mitigates hallucination, but dense retrieval struggles with the complex reasoning paths of multi-hop question answering, while graph-based RAG captures multi-step relationships at the cost of severe semantic drift and high online latency from noisy global graph traversals.

ISO-RAG applies isoperimetric principles to control noise during retrieval, keeping the graph traversal local and relevant instead of drifting across the whole graph — a structured-RAG technique aimed at multi-hop QA accuracy with bounded latency.

Why read it A concrete structured-RAG contribution targeting the multi-hop retrieval gap — relevant to RAG system design and knowledge-graph retrieval.
arXiv

RestoreBench: can AI agents restore power-flow convergence?

LLM agents increasingly automate multi-step engineering workflows through tool use, interpretation of intermediate results, and iterative planning. Diagnosing and resolving non-convergent power-flow cases is a promising but largely unexplored application, since it requires engineering judgment, experimentation, and decision-making within constrained action spaces.

RestoreBench turns that into a benchmark: can an agent bring a simulated power grid back to convergence, and how does it behave under constrained actions? It is a concrete evaluation of agents in critical infrastructure, following the same spirit as physical-impact agent benchmarks.

Why read it A concrete agent benchmark for critical-infrastructure operations — relevant to agent reliability and autonomous network management.
Uber

Uber's software factory: 70% of pull requests now agent-attributed across 3,600 skills

Uber reports that more than 70% of pull requests are now attributed to local or cloud AI agents, supported by a skill library exceeding 3,600 entries and more than 30,000 agent skill executions per day across code review, self-healing CI failures, and end-to-end PR completion.

The economics have been tuned hard: cost per 1,000 model requests fell roughly 34% from its peak and cost per agent session fell about 52%, making large-scale agent adoption cost-effective.

Why read it A concrete, production-scale agent-driven software development case study — relevant to LLM agents in the SDLC and agent cost engineering.
arXiv

Sliding-window attention with sinks beats post-trained linear attention on long contexts

Linear attention was proposed to escape the quadratic scaling of transformer attention, but a new study finds that sliding-window attention (SWA) with sink tokens can outperform post-trained linear-attention models by 2-10x on long-context reasoning tasks such as Needle-in-a-Haystack and BABILong.

SWA needs no post-training, is fast and memory-efficient, and its advantage over linear attention holds even after the linear models are post-trained — a direct challenge to the assumption that linear attention is the better long-context trade-off.

Why read it A concrete inference-architecture result with direct implications for long-context serving memory costs — relevant to LLM infrastructure choices.
Baseten

The efficient frontier of LLM inference: trade-off techniques vs frontier-pushing techniques

Baseten frames LLM serving around the efficient frontier: some techniques trade one outcome for another along the frontier — batch sizing, tensor versus expert parallelism, attention data parallelism — while others push the entire frontier outward, such as kernel optimization, speculative decoding, and prefill/decode disaggregation.

The practical note is that the frontier is jagged: small configuration changes have disproportionate effects, so production deployments need empirical sweeps rather than intuition, and frontier-pushing techniques compound (2x hardware times 2x software equals 4x serving).

Why read it A concrete, current framework for inference engineering decisions — relevant to serving cost, latency, and throughput trade-offs.
Research & World Models
Apache

Apache Iggy graduates to a Top-Level Project: Rust message streaming with VSR consensus

Apache Iggy, a persistent message-streaming platform written in Rust, graduated from the Apache Incubator to a Top-Level Project. It uses a thread-per-core architecture with io_uring for disk and network I/O, achieving single-digit-millisecond P99+ latencies.

Notably, it uses Viewstamped Replication Revisited (VSR) for consensus rather than the more common Raft, a choice that shapes its fault-tolerance and performance profile for high-scale data infrastructure.

Why read it A concrete distributed-systems milestone with a distinctive consensus choice — relevant to cloud-native data infrastructure.
Neon

Neon's Lakebase Postgres autoscales compute independently from durable state

Neon's Lakebase Postgres decouples compute from storage so production databases can change compute size tens of thousands of times per month — the average production database resizes about 32,000 times, or once every 81 seconds. Compute nodes run Postgres, execute queries, and cache on local NVMe, but own no durable state.

All durability and history live in a separate storage layer built on WAL replication via safekeepers, page reconstruction by pageservers, and long-term object storage — a concrete pattern for elastic, stateless database compute.

Why read it A concrete cloud-native database architecture — relevant to distributed systems and elastic Postgres deployments.
