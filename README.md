# Decode

> **Making difficult technical material understandable.**

A **personalized daily news digest** for [Viswa Kumar](https://www.viswakumar.com) — Senior Systems Architect in the telecom field, focused on Private 5G (packet core) and the intersection of network intelligence and AI.

Curated and delivered daily by **Sarathy 🪆** (the assistant).

Each edition is a short, opinionated list of 10-11 items. Every item has:

- **TLDR** — a couple-paragraph summary, enough to decide whether it's worth your time
- **Why read it** — why it matters (generic guidance; the site is public)
- **Link** — to the original article / paper
- **og:image** — the source article's thumbnail where available
- **Categories / tags / source / domain** — per-item metadata that drives the native word cloud and filters
- **Mermaid diagrams** — optional concept illustrations rendered client-side

The day page uses a **native Quarto listing** (`categories: cloud`) over the day's story files, so the topic word cloud, category filters, and pagination are generated by Quarto itself — no custom template or CSS.

**Site**: <https://decode.viswakumar.com>

## Structure

```
.
├── _quarto.yml            # Quarto website config (logo, theme, mermaid header include, output → docs/)
├── _includes/
│   └── mermaid.html       # Loads Mermaid + initializes {mermaid} cells → SVG client-side
├── index.qmd              # Home page — title, tagline, edition listing (RSS feed)
├── logo.svg               # Decode logo (signal-bars mark), also the favicon
├── styles.css             # Story body / label / mermaid styling
└── posts/
    ├── _metadata.yml      # Per-post defaults
    └── YYYY-MM-DD/
        ├── index.qmd      # Day edition page (native Quarto listing over stories/)
        └── stories/       # One qmd file per news item, each with its own
                           # categories/tags/source/domain/link/og:image/TLDR/why/mermaid.
                           # The listing auto-generates the word cloud + filters.
```

## Building

```bash
quarto render        # from the project root → builds the site into docs/
```

Quarto ≥ 1.x is required (installed on this host).

## Curation pipeline

A cron job runs daily at 04:00 America/New_York: it collects candidates (HN, arXiv, Reddit RSS, X, aggregators), selects the best 10-11 stories for the reader's interests, writes one qmd per story under `stories/`, renders, commits, and pushes. Uttaram MCP is the first choice for search and crawl; direct fetch is the fallback.
